# Dead Zone Protocol

เว็บเกมวางแผนแบบร่วมมือที่ได้แรงบันดาลใจจากวงรอบการเล่นของ Zombicide 2nd Edition โดยใช้ชื่อ ตัวละคร แผนที่ และงานภาพต้นฉบับใหม่ เกมบันทึกสถานะล่าสุดใน browser ให้อัตโนมัติ

## เล่นในเครื่อง

```bash
npm install
npm run dev
```

เปิด `http://localhost:5173`

## เป้าหมายภารกิจ

ควบคุมผู้รอดชีวิตทั้ง 6 คน ไปเก็บเสบียงที่ร้านขายยาและคลินิก จากนั้นพาทุกคนกลับจุดอพยพ ผู้รอดชีวิตคนใดคนหนึ่งถูกกำจัดถือว่าแพ้ทันที

## กติกาที่รองรับในรุ่นนี้

- ผู้รอดชีวิตมี 3 actions ต่อ activation และได้ action ที่ 4 เมื่อ adrenaline ถึง 7
- เดิน ค้นของ เปิดประตู ส่งเสียง เก็บ objective แลกอุปกรณ์ และโจมตี
- เลือกลำดับ activation ของผู้รอดชีวิตทั้ง 6 คน แต่ละคนมีความสามารถเฉพาะ
- อาวุธมีจำนวนลูกเต๋า ค่าแม่นยำ damage ระยะ และระดับเสียงต่างกัน
- Line of sight แนวตรง, targeting priority และ friendly fire สำหรับการยิงพลาด
- การออกจากโซนที่มี zombie ใช้ action เพิ่มหนึ่งครั้งต่อ zombie
- Walker, Brute และ Abomination ทำ 1 action; Runner ทำ 2 actions
- Zombie เลือกทางสั้นไปยังผู้รอดชีวิตหรือแหล่งเสียง แล้วเกิดใหม่จาก spawn zones
- การค้นทำได้ครั้งเดียวต่อ activation ในอาคารที่ไม่มี zombie
- ปุ่ม Undo และ `Ctrl+Z` ย้อน action ล่าสุด รวมผลการทอยลูกเต๋า
- Auto-save สถานะปัจจุบันใน `localStorage`
- เลือกเล่นได้ 4 ภารกิจ: เส้นทางเสบียง, เมืองดับไฟ, ยาเข็มสุดท้าย และวงล้อม
- Dice tray พร้อม animation ซึ่งทำงานเฉพาะตอนโจมตีหรือใช้ไอเท็ม โดยใช้จำนวนลูกเต๋าและค่าเป้าหมายจากการ์ดนั้น
- ชุดปฐมพยาบาลใช้ 1 action ทอย 1 ลูก; 4+ ฟื้นฟู 1 HP และใช้แล้วทิ้ง
- Token ใช้ภาพตัวละคร/ซอมบี้จริง พร้อมคู่มือคำอธิบายอาวุธและศัตรู
- ทิ้งอุปกรณ์จาก inventory ได้ฟรีด้วยปุ่ม `×`

## คำสั่งตรวจสอบ

```bash
npm test
npm run build
```

นี่คือ core digital edition ที่เล่นภารกิจหลักได้ครบ ไม่ได้คัดลอกชื่อ โลโก้ การ์ด หรือ artwork ของผลิตภัณฑ์ต้นฉบับ ระบบเสริมอย่างรถ, companion, campaign และภารกิจจาก expansion ยังไม่รวมอยู่
